---

## Overview

Free Windows beta for using Minecraft schematics as manual Hytale build plans. Review suggested Hytale material replacements, inspect full 3D models, current-layer 3D views and 2D layer plans, and manually track placed blocks and layer completion.

Citadel Desk is a standalone reference planner. It does not automatically place blocks in Hytale or export native Hytale schematics. Material matching and rendering have known beta limitations. Users connect their own Hytale assets for the catalog and textures; game assets are not bundled.
