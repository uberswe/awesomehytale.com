## Overview

Free in-game Hytale beta mod from the creator of Citadel Desk for following Minecraft schematics layer by layer. Open a build into a textured 2D plan, zoom and pan with adjacent controls, switch layers, and return to gameplay with a passive top-left overlay. Numbered edges, filled-block counts and readable straight-run labels help builders count blocks.

Materials, manual replacements, block checks, layer completion, measurements and saved progress remain available under Tools. Inputs include .schem, .litematic and Minecraft structure .nbt; legacy .schematic is unsupported. The in-game import help explains the server-local folder workflow. Windows file drops and arbitrary client uploads are not supported.

Beta 19 was tested on Hytale 0.7.6. Native prefab/asset-pack export is available for compatible builds after a separate review; unsupported states, shapes and footprints remain blocked. Viewer matches can be approximate. Progress is manual, with no automatic placed-block detection or ghost projection. Use backups and start with a small build.
